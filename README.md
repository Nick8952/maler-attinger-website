# maler-attinger-website

Verkaufs-Demo für Attinger Maler- + Tapeziergeschäft, Zürich – Next.js 16 (App Router), statischer Export auf
GitHub Pages, vorbereitet für Sanity (CMS) und Vercel (Hosting).

- Demo: https://nick8952.github.io/maler-attinger-website/
- Anleitung und Architektur: [CLAUDE.md](CLAUDE.md) und [docs/](docs/)

```bash
npm install
npm run dev            # http://localhost:3000/maler-attinger-website/
npm run build:pages    # statischer Export → out/
npm run vorschau:pages # Export lokal wie auf GitHub Pages testen
```
